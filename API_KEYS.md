# API keys and environment configuration

**No API key is required for this project.**

The simulator runs entirely offline with synthetic price paths and writes local
JSON/markdown artifacts. The recurring loop runner is paper-only: no wallet,
no exchange credentials, no network calls, no keys.

`paper_config.json` contains simulation parameters only (abstract units, not
USD). Do not add credentials to it.

I did not search GitHub for "free" keys or reuse credentials from public repos;
there is no legitimate key to find for this codebase.
